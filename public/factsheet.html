01 · Theory

The science it rests on

Neo-CohMetrix is a modern re-implementation of the multilevel discourse comprehension tradition. Each idea below maps directly to a design decision in the engine.

Multilevel discourse comprehension

Comprehension is not one skill but a stack — surface code, an explicit textbase, and a situation model (Kintsch's construction–integration; Graesser & McNamara's Coh-Metrix program).

→ maps to layers L0–L11, grouped into 5 discourse levels + a cross-level meta layer.

Principal-component profiling

The original Coh-Metrix reduced thousands of texts to a handful of principal components that track readability and cohesion across grade levels.

→ maps to 8 composite factors (F1–F8), PCA-analog dimensions rolled into one overall score.

Zone of proximal development

Difficulty is relative to a reader. A text that stretches one learner overwhelms another (Vygotsky).

→ maps to L11 reader-adaptive scoring, which re-scores challenge against a learner profile.

Genre & register expectations

A lab report and a personal narrative are "good" in different ways; cohesion norms shift with genre.

→ maps to genre-aware scoring across 162 genres, adjusting metric applicability and weights.

Explainable assessment

A score is only useful if a writer can see why. Evidence beats black-box numbers.

→ maps to per-metric evidence excerpts + verdicts and prioritized LLM tutor feedback.

Language-relative analysis

Discourse features are expressed differently across languages; analysis should follow the text's language.

→ maps to language-aware LLM prompting driven by each document's language metadata.

02 · Technology

How it's built

A Node/Express backend and a zero-build vanilla-JS front end. NLP does the deterministic work; a single LLM gateway does the interpretive work. Every model call goes through one chokepoint.

Hybrid NLP + LLM

Deterministic metrics come from local NLP (compromise, natural, wink-nlp). LLM calls handle semantics, rhetoric, stance and feedback — routed through one abstraction with token tracking.

Parallel analysis pipeline

Layers run in four dependency-ordered groups so fast NLP work never waits on slow LLM work. The reader-adaptive meta layer runs last, over everything.

Real-time streaming

Server-Sent Events push layer-by-layer (and file-by-file, for batches) progress to the browser as analysis runs — no polling, no spinner-in-the-dark.

Multi-provider LLM gateway

One abstraction over Anthropic / OpenAI / Azure with structured-JSON parsing, batching, and language-aware prompting. Swap providers without touching layer code.

Durable, user-scoped storage

Google Cloud Storage with an in-memory fallback for local dev. Every artifact is namespaced under users/{email}/projects/… — projects, documents, metadata, results.

Auth, quota & i18n

OAuth gateway with cached token verification and a super-admin panel; per-user token/cost quotas; hash-based internationalization with right-to-left support.

03 · Applications

Where it fits

One engine, several jobs — diagnostic feedback, corpus research, and self-directed revision.

Writing instructors

Diagnostic breakdowns that show why an essay is (or isn't) cohesive — not just a grade. Map cohesion metrics onto your own rubric for aligned, scored reviews.

Researchers

The full metric set across every discourse level, for corpus and readability studies. Metrics tie back to published constructs; batch analysis handles many documents at once.

Students & self-learners

Evidence-backed feedback that explains each metric in plain language and suggests concrete revisions, with reader-adaptive difficulty tuned to level.

Genre-specific assessment

162 genres across 23 categories, each with its own expectations — a narrative, a lab report, and an opinion piece are judged by different, appropriate norms.

Multilingual programs

Analysis follows each document's language metadata, and the interface localizes with right-to-left support — usable beyond English-only settings.

Rubric-driven grading

Upload a grading framework and the system maps metrics to each criterion, producing a structured, per-criterion evaluation you can defend.

04 · Impacts

What changes

Framed as mechanisms the design produces — not measured study outcomes.

Feedback becomes traceable

Because every metric carries evidence excerpts and a verdict, feedback points to specific sentences instead of asserting a verdict from nowhere — the reasoning is inspectable.

Assessment adapts to genre and reader

Genre profiles change which metrics apply, and the meta layer re-scores difficulty per learner — so the same text is judged appropriately in different contexts.

Scale without losing the thread

Batch analysis with upfront cost estimates and streaming progress lets a class set or research corpus be processed in one run while staying observable.

Provider and cost stay under control

A single LLM gateway with token tracking and per-user quotas means model spend is measured at one chokepoint and providers can be swapped without rewrites.
